HOW TO GO LIVE
iPhone / iPad: Safari can't do Bluetooth — and neither can Chrome, Edge or Firefox on iPhone (Apple makes them all use Safari's engine). Install the free Bluefy – Web BLE Browser app, open this page in it, and allow Bluetooth. Then tap START LOOKING (or + TRACK A DEVICE).
Android: Use Chrome. Turn on Bluetooth and Location, and allow Chrome “Nearby devices”. To see everything around you, open chrome://flags/#enable-experimental-web-platform-features, set it to Enabled, relaunch. Without the flag you can still track devices one at a time.
Computer: Chrome or Edge on Windows/Mac (same flag for the full scan). Firefox and Safari can't do Bluetooth.
Live Mode only reads the public “I'm here” broadcasts devices already send. It doesn't pair, doesn't connect (except in Bluefy's link check, which just opens and closes a connection to the one device you picked), and nothing leaves your phone. Many phones change their Bluetooth ID every few minutes on purpose, so the same phone can show up as a “new” device.
